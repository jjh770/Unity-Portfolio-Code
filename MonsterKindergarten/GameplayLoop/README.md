# GameplayLoop

클릭으로 재화를 얻고, 자동 생산과 스폰으로 방치 성장을 이어가며, 같은 등급 슬라임을 머지해 상위 등급을 해금합니다.

## 파일

| 파일 | 역할 |
|---|---|
| [`Clicker.cs`](./Clicker.cs) | 누른 시간과 이동 거리로 클릭·드래그를 구분합니다. |
| [`PointCalculator.cs`](./PointCalculator.cs) | 수동·자동 클릭별 고정·비율 업그레이드를 조합해 획득량을 계산합니다. |
| [`AutoClicker.cs`](./AutoClicker.cs) | 활성 슬라임별 자동 생산 주기를 관리하고 Gameplay 정지 상태를 반영합니다. |
| [`MergeManager.cs`](./MergeManager.cs) | 같은 등급 여부를 검증하고 상위 등급 변경, 상태 저장, 풀 반환을 조정합니다. |
| [`SpawnManager.cs`](./SpawnManager.cs) | 저장된 활성 슬라임 복원, 자동 생성과 스폰 관련 업그레이드를 적용합니다. |

## 게임 루프

```text
슬라임 클릭 → 재화 획득 → 업그레이드 구매
                         ↓
자동 생산 ← 생산량 강화   스폰 ← 생성 간격·최대 개수 강화
   ↓                       ↓
같은 등급 드래그 머지 → 상위 등급 해금 → 더 높은 획득량
```

## 오프라인 보상과 연결

- 온라인 자동 생산과 오프라인 보상은 동일한 `PointCalculator` 계산 규칙을 사용합니다.
- 오프라인 보상이 대기 중이면 `GameManager.IsGameplayActive`를 통해 자동 생산과 스폰을 함께 정지합니다.
- 보상 수령·연출 완료 후 Gameplay가 다시 활성화됩니다.

## 설계 포인트

- 클릭과 드래그를 동일 입력에서 명확히 구분합니다.
- 기본 획득량, 고정 보너스, 비율 보너스 계산을 UI나 슬라임 클래스에서 분리합니다.
- 저장 데이터 복원 시 기존 슬라임이 있으면 Grade1을 추가 생성하지 않고, 복원할 슬라임이 없을 때만 최초 슬라임을 생성합니다.
